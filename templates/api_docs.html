DriveNow API

Base URL: http://127.0.0.1:8000/api/

Usuarios

POST /api/usuarios/crear/ Registrar nuevo usuario

Request body

{
  "nombre":   "Ana García",
  "cedula":   "1234567890",
  "correo":   "ana@email.com",
  "licencia": "LIC-00123"
}

Response 201

{
  "id":       1,
  "nombre":   "Ana García",
  "cedula":   "1234567890",
  "correo":   "ana@email.com",
  "licencia": "LIC-00123"
}
201 Creado   400 Datos inválidos   409 Cédula o correo duplicado
GET /api/usuarios/ Listar todos los usuarios
200 OK
GET /api/usuarios/<id>/ Detalle de un usuario
200 OK   404 No encontrado

Vehículos

GET /api/vehiculos/ Listar todos los vehículos

Query params opcionales

?disponible=true   → solo vehículos disponibles
?disponible=false  → solo vehículos ocupados
200 OK

Reservas

POST /api/reservas/crear/ Crear una reserva (por placa del vehículo)

Request body

{
  "usuario_id":     1,
  "placa_vehiculo": "ABC-123",
  "fecha_inicio":   "2026-04-01",
  "fecha_fin":      "2026-04-05"
}

Response 201

{
  "id":          1,
  "usuario":     { ... },
  "vehiculo":    { "placa": "ABC-123", ... },
  "fecha_inicio":"2026-04-01",
  "fecha_fin":   "2026-04-05",
  "estado":      "PENDIENTE"
}
201 Creada   400 Fechas inválidas   404 Usuario o vehículo no existe   409 Vehículo no disponible
GET /api/reservas/ Listar todas las reservas
GET /api/reservas/<id>/ Detalle de una reserva
200 OK   404 No encontrada
POST /api/reservas/<id>/cancelar/ Cancelar una reserva
200 Cancelada   404 No encontrada   409 Ya cancelada

Pagos

POST /api/pagos/ Registrar un pago para una reserva

Request body

{
  "reserva_id":  1,
  "monto":       250000.00,
  "metodo_pago": "TARJETA_CREDITO",
  "fecha_pago":  "2026-04-01"
}

Métodos válidos

EFECTIVO
TARJETA_CREDITO
TARJETA_DEBITO
TRANSFERENCIA

Response 201

{
  "id":                  1,
  "reserva":             1,
  "monto":               "250000.00",
  "estado_pago":         "APROBADO",
  "estado_pago_display": "Aprobado",
  "metodo_pago":         "TARJETA_CREDITO",
  "metodo_pago_display": "Tarjeta de Crédito",
  "fecha_pago":          "2026-04-01"
}
201 Registrado   400 Datos inválidos   404 Reserva no existe   409 Ya pagada o cancelada
GET /api/pagos/<id>/ Detalle de un pago
200 OK   404 No encontrado
