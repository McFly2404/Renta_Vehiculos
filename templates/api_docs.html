Usuarios

POST /api/usuarios/crear/ Registrar usuario

GET /api/usuarios/ Listar usuarios
GET /api/usuarios/1/ Detalle de usuario

Vehiculos

GET /api/vehiculos/ Listar flota 
?disponible=true   -> solo vehiculos disponibles
?disponible=false  -> solo vehiculos ocupados

Reservas

POST /api/reservas/crear/ Crear reserva 
{
  "usuario_id": 1,

}
GET /api/reservas/ Listar reservas
POST /api/reservas/1/cancelar/ Cancelar reserva

  "metodo_pago": "TARJETA_CREDITO",
  "fecha_pago": "2026-06-01"
